git status — показывает общую картину: в какой вы ветке, какие файлы изменены, какие добавлены в зону подготовки (staged), а какие еще не отслеживаются Git.git diff — показывает конкретные изменения (что именно удалено или добавлено по строкам) в рабочей директории, которые еще не добавлены через git add (сравнение с индексом).git diff --staged (или --cached) — показывает изменения, которые уже подготовлены с помощью git add и готовы отправиться в следующий коммит (сравнение индекса с последним коммитом).
Главное различие заключается в том, что Git — это программа для отслеживания изменений в коде на вашем компьютере, а GitHub — это сайт в интернете для хранения этого кода и командной работы.
